** Constraint Satisfaction

States are now factored: a set of variables, each of which has a value.

Constraint satisfaction problem defined by

- $\mathcal{X}$: a set of variables, $\{X_1, \dots, X_n\}$
- $\mathcal{D}$: a set of domains for the variable values,  $\{D_1, \dots, D_n\}$

  - Each $D_i$ is a set of allowable values $\{v_1, \dots, v_k\}$ for variable $X_i$

- $\mathcal{C}$ a set of constraints specifying allowable combinations of values

  - Each constraint $C_j$ is a pair, $\langle scope, rel \rangle$ where

    - $scope$ is a tuple of variables participating in the constraint, and
    - $rel$ is a *relation* defining the values that those variables can take.
